# 网易云音乐 · MyGo Music 插件

在 [MyGo Music](https://github.com/egoist/mygo-music) 中搜索和播放网易云音乐。需要 MyGo Music 0.1.21 或更新版本，无需额外服务。

网易云 CDN 封面使用 `{size}` 模板，由主程序按列表、卡片及播放页所需尺寸请求缩略图，减少首次下载和大图解码。0.1.20 之前的主程序不支持此模板，使用前请先升级。

## 安装和使用

1. 打开 MyGo Music → 设置 → 插件 → `+` → 从 GitHub 安装，填入 `sogud/mygo-music-netease`。也可从 [Releases](https://github.com/sogud/mygo-music-netease/releases) 下载 ZIP 后从本地安装，或选择本项目文件夹。
2. 安装后，在来源选择器中选择 **网易云音乐**。
3. 点击 **登录**，用网易云音乐手机 App 扫码，访问自己的歌单和喜欢的音乐。
4. 每日推荐、私人雷达和个性化歌单集中在 **发现音乐**；侧栏另有 **私人漫游**、**我喜欢的音乐**、**我收藏的专辑**、**我的播客** 和 **排行榜**。推荐歌单加载失败时，可在该区域点 **查看全部** 重试，其他入口仍可使用。

## 功能

- 歌曲、专辑、歌手、歌单和播客搜索，支持翻页与输入建议。
- 推荐歌单、排行榜、歌单详情，专辑和歌手详情。
- 登录后的每日推荐、私人雷达、个性化歌单，以及持续补充歌曲的私人漫游、熟悉的歌、新发现和心动模式。
- 网易云 App 扫码登录、会话恢复、个人歌单、喜欢列表、喜欢/取消喜欢、收藏专辑、关注歌手、订阅播客。
- 自建歌单的新建、改名、删除和歌曲排序；将歌曲添加到歌单或从中移出，已存在的歌曲不会重复加入。
- 登录后的最近播放，以及「我收藏的专辑」页。
- 标准、高音质和无损音质，可在插件设置里限制最高档位。
- 逐字歌词和翻译：登录后从桌面接口取回每个字的演唱时间，MyGo Music 的律动与歌词页按字点亮；无逐字数据的歌曲退回 LRC 行级歌词和翻译。
- 歌曲和播客节目的评论，支持分页、点赞与发表。
- 登录后从「我的播客」读取网易云已订阅播客，浏览、分页播放节目；不修改订阅。

## 私人漫游没有歌曲时

私人漫游、熟悉的歌和新发现依赖网易云的个性化服务。关闭该服务时，账号即使已经登录，电台接口也可能返回成功状态和空歌曲列表。

请在网易云官方 App 的 **设置 → 消息和隐私 → 个性化服务** 中确认该开关已开启，然后回到 MyGo Music 点击 **开始收听**。该隐私设置由你在官方 App 中管理。若已开启但仍没有歌曲，请稍后重试。

电台卡片会显示这项前置条件。返回空列表时，插件会查询个性化服务设置；确认已关闭时，返回带有恢复说明的错误。重新开始收听会重新请求歌曲。

## 云盘、听歌排行和评论

发现音乐页新增音乐云盘、最近一周和所有时间听歌排行。云盘只读分页，不上传或删除歌曲；私有歌曲直接使用云盘元数据，官方路径下播放仍以当前账号权限为准（开启外部音源时见下文）。排行保留网易云返回的顺序，当前宿主不支持播放次数列；登录后只上报「开始播放」，所以最近播放会随播放更新，收听时长不会计入排行。

评论优先显示接口提供的最多 20 条热门评论，之后按时间加载最新评论；按评论 ID 去重并分别维护显示位置与服务端位置。

支持宿主可解码的 AAC/M4A/MP4 音频，仍拒绝试听地址及无完整播放权限的结果。

## 音质设置

插件设置里的「最高音质」是上限，默认「跟随播放器」。播放器要求无损而你把上限设成「高音质」时，插件只请求 320k；播放器要求更低时不会抬升。上限只影响请求档位，不改变播放器自己的音质选项。

## 外部音源（可选，本 fork 新增）

默认关闭。开启后，播放会先请求一个 LX 音源脚本解析直链；拿不到合规直链时静默回落官方播放，登录态与账号数据不受影响。

1. 打开插件设置，开启「使用外部音源」。
2. 在「LX 音源脚本地址」填入完整的 LX 脚本地址，例如：

   ```text
   https://source.shiqianjiang.cn/api/script/lx?key=你的密钥
   ```

3. 保存后播放即可。更换地址（含换密钥）后，下一次播放会重新读取脚本。

主脚本取不到直链时，可以在「备用 LX 脚本地址」再填一个地址，插件会按「主脚本 → 备用脚本 → 官方」的顺序依次尝试。两种常见的 LX 服务协议（GET 加 `songId`、POST 加 `musicId`）会自动识别，不需要手工选择。

插件只读取脚本文本里声明的接口地址、密钥与是否支持网易云（`wy`），**不会执行脚本**。脚本没有 `wy`、地址填错或服务不可用时，播放仍由官方路径完成。

需要说明的差异：

- 走外部音源时，上面的「拒绝试听地址及无完整播放权限的结果」不再适用——插件不判断会员状态，音源给什么就播什么。
- **原本因会员权限置灰的歌曲会恢复为可点击**（插件的 `unavailable` 标记在开关打开后一律放行）。代价是：如果音源也拿不到这首，点击后会提示播放不可用，而不是提前置灰。
- **选「无损」时请求的是音源的最高档**（网易云的 `master`），实测多为 24bit/192kHz、少数 24bit/96kHz；音源没有高解析的歌曲会自动给 16bit/44.1kHz 的普通无损，插件按实际字节判定容器，不会把 MP3 标成无损。不想下载这么大的文件时，开启「无损档不请求最高音质」，此时只请求普通无损（`flac`）。
- 网易云 CDN 常返回 http 直链，插件会改成同主机的 https 再交给宿主。
- 高解析单曲可达 170 MB 以上，首次缓冲和拖动会比普通无损更吃网络。
- 外部音源的实际可用性由第三方服务决定，本插件不对其稳定性或授权合规性负责。

> **权限提示**：脚本与接口域名由你填写、无法预先枚举，因此插件会申请访问任意网站。关闭「使用外部音源」后不会发出任何音源请求。
